# Stone Paper Services

A professional ePublishing and book typesetting company website built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- Responsive marketing website with home, services, portfolio, pricing, industries, about, and contact pages
- Animated sections using Motion
- Dark mode support
- Portfolio gallery with category filtering
- SEO-friendly page meta tags

## Tech stack

- React 18
- TypeScript 5
- Vite 6
- Tailwind CSS 3
- shadcn/ui primitives
- Motion

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the site.

## Build

```bash
npm run build
npm run preview
```

## Lint and type check

```bash
npm run lint
```

## Deploy to GitHub Pages

1. Create a new repository on GitHub.
2. Push this project to the `main` branch.
3. Go to **Settings → Pages → Build and deployment** and select **GitHub Actions** as the source.
4. The workflow in `.github/workflows/deploy.yml` will build and deploy the site automatically on every push to `main`.

If you use a custom domain, update the `base` value in `vite.config.ts` to `"/"` and configure the domain in the repository settings.
